隐私政策 English

ChannelFlow — Token Tools · 最后更新：2026-01-01 · 自安装之时起生效

一句话概括：本扩展不会将任何数据传出你的设备。

1. 概述

ChannelFlow — Token Tools（以下简称「本扩展」）是一款本地工具，用于查看并复制你自己的 Discord 授权令牌。本政策说明本扩展处理哪些数据以及如何处理。

2. 我们处理的数据

项目说明
Discord 授权令牌仅在你登录 discord.com 期间，被动读取你自己的 Discord API 流量中的 Authorization 请求头。
扩展偏好设置仅界面语言切换，不持久化保存。

本扩展不处理：密码、邮箱、聊天内容、浏览历史、cookies、支付信息，以及除 Discord API 之外任何网站的数据。

3. 数据如何被收集

本扩展通过 webRequest API 观察发往 https://discord.com/api/v9/* 的请求， 并读取 Discord 自身附加在这些请求上的 Authorization 请求头。仅在你安装本扩展并使用 Discord 时发生。

4. 数据如何存储

捕获到的令牌写入 chrome.storage.local——一个仅存在于你的设备的存储区域。 它不会同步到任何账户，其他扩展或网站也无法访问。

5. 数据用途

令牌仅用于一个目的：在扩展弹窗中显示（默认打码），并在你点击「Copy」时复制到剪贴板。不进行任何其他处理。

6. 共享与传输

无。本扩展不含任何分析、跟踪、广告、远程代码，也不存在任何通过网络发送数据的代码路径。 令牌绝不会通过本扩展离开你的设备。

7. 保留与删除

点击弹窗中的 Clear 立即删除令牌。卸载本扩展会移除其全部本地数据。本扩展不会在其他任何地方创建备份或副本。

8. 安全性

最小权限集（见扩展列表页）。无远程脚本、无第三方依赖。令牌在界面中默认打码显示。

9. 您的权利

你可以随时查看、复制和删除令牌。由于所有数据均保存在本地，不存在需要请求删除的服务器端副本。

10. 政策变更

若本政策发生变更，更新版本将发布在此 URL，并更新「最后更新」日期。
